### Tensorflow

TensorFlow is an open‑source machine learning framework from Google for building, training, and deploying models, especially deep neural networks. It works by representing computations on multidimensional arrays (tensors) as operations that can run efficiently on CPUs, GPUs, and TPUs using an execution engine under the hood.

### What TensorFlow is

* TensorFlow is a software library for machine learning and AI that focuses on numerical computation and deep learning.

* It was developed by Google Brain and released as open source, and is widely used for tasks like image recognition, NLP, time‑series forecasting, and recommendation systems.

* The ecosystem includes Keras (high‑level APIs), TensorBoard (visualization), data input pipelines, and deployment tools for mobile, web, and cloud.
