### Troubleshooting Skills

**Key takeaways** 

1. Start with the skills validator tool — it catches structural problems before you spend time debugging other things
2. If a skill doesn't trigger, the cause is almost always the description — add trigger phrases that match how you actually phrase requests
3. If a skill doesn't load, check that SKILL.md is inside a named directory (not at the skills root) and the file name is exactly SKILL.md
4. If the wrong skill gets used, your descriptions are too similar — make them more distinct
5. For runtime errors, check dependencies, file permissions (chmod +x), and path separators (use forward slashes everywhere)
