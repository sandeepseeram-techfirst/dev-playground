# AI Engineering

AI engineering: the process of building applications with readily available foundation models.

### Model Adaptation Techniques
1. Prompt Engineering
2. RAG 
3. Fine-tuning
4. Agents
5. Dataset Engineering

### Note 
Training large language models (LLMs) requires data, compute resources, and specialized talent that only a few organizations can afford. This has led to the emergence of * model as a service *: models developed by these few organizations are made available for others to use as a service. Anyone who wishes to leverage AI to build applications can now use these models to do so without having to invest up front in building a model.
